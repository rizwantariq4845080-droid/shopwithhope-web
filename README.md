# Shop with Hope Website

Next.js site for **Shop with Hope** (`shopwithhope.pk`) — imported branded laptops in Gulberg Lahore.

## Features

- Shop with Hope branding
- Brand categories: Dell, HP, Lenovo, Microsoft, Accessories
- Featured laptop stock section
- WhatsApp order buttons + floating chat
- Address / contact / hours

## Local development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Deploy on Vercel

1. Push this repo to GitHub
2. Import project on [vercel.com](https://vercel.com)
3. Deploy
4. Add custom domain `shopwithhope.pk` in Vercel → Settings → Domains
5. Update DNS/nameservers in PKNIC as Vercel shows

## Edit content

Update shop details and products in `src/lib/site.ts`.
